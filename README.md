# spotted — security & development

Portfolio personal minimalista de pentesting, Linux y desarrollo.

## Ejecutar

Abre `index.html` en tu navegador. No necesita dependencias ni compilación.

## Publicar en GitHub Pages

1. Crea el repositorio `whospotted.github.io` en GitHub.
2. Sube `index.html`, `style.css`, `script.js` y `.nojekyll` a la raíz de la rama `main`.
3. En **Settings → Pages**, selecciona **Deploy from a branch**, `main`, `/ (root)`.
4. Tu sitio aparecerá en `https://whospotted.github.io/`.

## Personalizar

- Edita los textos, habilidades y proyectos en `index.html`.
- Cambia el color de acento mediante `--red` en `style.css`.
- Sustituye los enlaces generales de proyectos por las URL específicas de cada repositorio.

Los proyectos reflejan áreas de trabajo personales, no certificaciones profesionales.
